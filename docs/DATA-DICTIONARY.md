# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 region, tile。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `x0`、`y0`、`x1`、`y1`、`min_cells` 排列。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

瓦片为整数网格上的左闭右开矩形。扫过相邻 X 边界，按 Y 区间并集求有效像元。输入重叠多计量与真实缺口独立提供。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。

## 补测包字段

补测包由系统生成，不进来源 CSV。每个包字段如下：

| 字段 | 含义 |
|---|---|
| `id` | 由业务组、规则版本、来源指纹、作业区和包内矩形共同决定的稳定标识 |
| `case` | 业务组；包边界按业务组划分，不跨组并包 |
| `version` | 生成该包的规则版本 |
| `source` | 来源文件指纹，与批次清单的 `sha256` 一致 |
| `cells` | 包内未覆盖像元数，等于该业务组缺口 |
| `bounds` / `rects` | 包的外接范围和矩形分解，均在作业区内 |
| `status` | `PENDING`、`DISPATCHED`、`CLOSED` 或 `SUPERSEDED` |
| `net_cells` / `remaining_cells` | 累计净覆盖与尚未覆盖的像元数 |
| `supersedes` / `superseded_by` | 规则版本更新后的新旧包对应关系 |

覆盖报送使用 `{"rects":[[x0,y0,x1,y1],…]}`，坐标为整数，左闭右开；作业区外面积和重复报送的重叠多计量不计入净覆盖。
